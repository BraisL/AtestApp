# AtestApp

Aplicación local para preparar diligencias y atestados en Windows 10 y 11 de 64 bits. Funciona sin conexión. La serie **0.x** está en desarrollo.

**[Descargas y versiones de AtestApp](https://github.com/BraisL/AtestApp/releases)**

En la última versión publicada encontrarás dos opciones:

| Archivo | Cómo se utiliza |
| --- | --- |
| **AtestApp-…-Portable-x64.exe** | Descarga y abre el EXE, sin instalación. Para actualizar, descarga el nuevo portable, cierra la aplicación y sustituye el anterior. |
| AtestApp-…-Setup-x64.exe | Instala una vez. Las siguientes actualizaciones se descargan desde la aplicación y se aplican con **Reiniciar y actualizar**. |

Ambos incluyen lo necesario para funcionar sin descargar componentes adicionales. Los datos se guardan en el equipo; usa la exportación e importación JSON para trasladar tu trabajo a otro ordenador. Conserva una copia de los documentos importantes.

Los ejecutables todavía no tienen firma digital: Windows puede mostrar un aviso de editor desconocido. El portable no elimina ese aviso.

El [historial de versiones](https://github.com/BraisL/AtestApp/releases) recoge las novedades. `latest.yml` y `.blockmap` son archivos auxiliares de la actualización automática; no tienes que abrirlos. `SHA256SUMS.txt` permite verificar las descargas.

AtestApp se distribuye con **código cerrado**. Este repositorio contiene únicamente la información de distribución; los enlaces «Source code» que GitHub genera automáticamente no contienen los originales de la aplicación. Está previsto habilitar una solicitud de los archivos originales, sujeta a autorización; todavía no está disponible.
